# Blazed Kitty brand assets

Storage branch for design work. No app code here, and nothing on this branch triggers a deploy.

| Folder | What's inside |
|---|---|
| `photos/standing_poses` | 49 model photos, simple standing poses, all 9 designs (latest) |
| `photos/baddie_poses` | 45 model photos, wild stoner-baddie poses, 8 designs |
| `photos/mommy_baddie` | 5 Mommy Needs A Joint baddie shots |
| `photos/first_shoot_pro` | First Nano Banana Pro shoot (25) |
| `photos/very_hot_first` | First Very Hot shoot (15) |
| `print/` | Print-ready PNGs for the 9 house designs (300 dpi) and panties (`panty_669`) |
| `print/very_hot_colorways` | Very Hot print files in 12 colors per product |
| `mockups/` | Flat mockups built from Printful templates |
| `boards/` | Contact sheets and the Pinterest mood board |
| `tools/` | Scripts that make the print files, mockups and model photos |
| `fonts/` | Font files used by the designs |
| `NOTES.md` | Brand rules: house style, fonts, products, photo direction, costs |
